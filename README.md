# Data Analysis Projects

This repository contains a collection of Python-based data analysis and visualization projects.

## Project 1: Sales Dashboard
- **Dataset**: Superstore Sales Dataset (Kaggle)
- **Goal**: Analyze sales and profit trends, build interactive visualizations
- **Tools**: Python, Pandas, Matplotlib, Seaborn
- **Highlights**:
  - Sales by category and region
  - Profit vs. discount analysis
  - Dashboard-style visualizations

## How to Run
1. Clone the repository
2. Install dependencies: `pip install pandas matplotlib seaborn`
3. Open the notebook: `Project1_Sales_Analysis_.ipynb`
4. Run cells to reproduce analysis and charts
